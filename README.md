## Deployment

### Podman Compose

```yaml
services:
  adguardhome-sync:
    image: ghcr.io/daemonless/adguardhome-sync:latest
    container_name: adguardhome-sync
    environment:
      - PUID=1000
      - PGID=1000
      - TZ=UTC
    volumes:
      - "/path/to/containers/adguardhome-sync:/config"
    ports:
      - 8080:8080
    restart: unless-stopped
```
